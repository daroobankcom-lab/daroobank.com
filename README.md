# DarooBank | داروبانک

DarooBank is planned as a Persian-first pharmaceutical knowledge and Iranian product/price intelligence platform. Clinical review, traceable evidence, product-level identity and verifiable price provenance are essential. It is **not an online pharmacy**.

## Current state

This repository currently contains **Phase 0–1 planning documentation only**. There is no running website, API, database, crawler, administration panel or clinical dataset. No sources have been licensed or approved for collection or republication. Proposed architecture is not implemented or production-ready. No application dependencies are needed to read the documents; do not deploy to production without explicit authorization.
