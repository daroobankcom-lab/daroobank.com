## Scope, setup and safety

The skill ecosystems describe agent-specific instructions; they are not dependencies of the Django application. Their installation instructions and optional toolchains vary (Node/Python, agent CLI, browser or Docker/LLM services); they were not installed. We examined root README, path inventories, root licences and a small selected set of relevant files, not all documentation, examples, dependency trees or every relevant skill. A fuller review is still needed before integrating any tool. In particular, no autonomous attack tools were used and no third-party systems were tested. Foreman GPL and any nested licence apply if its code is ever incorporated; do a fresh legal review before vendoring. No upstream content was copied into clinical claims.
